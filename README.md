# Garage Manager

A web app for running my mechanic workshop: customers, vehicles, work orders,
parts and labour costs, and profit per job.

## Why I'm building it
I work as a mechanic and study computer science. I wanted a tool that tracks
what each job really earns (cash profit and profit after my own time), helps me
budget, and balances my workload, while I learn PHP and Laravel by building it.

## Built with
Laravel, Livewire, SQLite

## Status
In progress: database and profit logic done, login working, building the
customer search and work order screens.
